## 验证结果

- `cargo build --workspace`、`cargo check --workspace`、`cargo fmt --all -- --check`、`git diff --check` 通过。
- `cargo test --workspace` 复跑：481 项通过，未设置 `ARENA_SKIP_LIVE`，包含真实进程、500 轮对局、1000 场回放门禁和沙箱执行检查。
- 第二批 CLI 6 项、地图公共接口 2 项复测通过；第一批 CLI 10 项回归通过。第二批覆盖无沙箱和沙箱实际运行、结构化参数／环境变量、构建迁移和完整资源声明。
- 新文档本地链接检查通过。前端代码与 WASM 接口未修改；原生回放链路由全量 Rust 测试覆盖，本批未另跑浏览器测试。

首轮全量测试有一项既有 `address_space_limit_aborts_the_malloc_bomb` 失败：日志出现内存分配失败，但 8 秒时进程未退出而被 wall watchdog 分类为 wall_timeout。当前主机 core_pattern 接入 WSL 崩溃收集；单项复测约 0.43 秒通过，随后相同命令的完整复跑全部通过。未改变该断言、放宽预算或把超时改记为内存限制；根因未单凭一次复测判定为已解决。该时序观察保留，不归因于策略性能。
